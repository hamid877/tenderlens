# TenderLens

TenderLens is an AI-powered tender document analysis system.

It allows users to upload tender documents and ask questions about
eligibility requirements, financial criteria, deadlines, certifications,
experience requirements, and other important tender information.

## Core Technologies

- Python
- RAG (Retrieval-Augmented Generation)
- FAISS
- BM25
- Sentence Transformers
- Cross-Encoder reranking
- LLM-based generation
- NLI-based answer verification
